| Q | Answer | Reason |
|---|--------|--------|
| 1 | **B. O(1)** | Index arithmetic (base + i × size) gives direct access. |
| 2 | **C. Insertion** | Adding an element is insertion. |
| 3 | **C.** Match required operations/constraints to each structure's strengths | Every structure has trade-offs. |
| 4 | **C. Time vs space trade-offs** | Extra memory (cache) is spent to save computation time. |
| 5 | **B. O(m + n)** | Sequential (non-nested) loops add. |
| 6 | **C. Linear data structure** | One predecessor and one successor per element. |
| 7 | **C. O(n)** | Drop the constant multiplier and lower-order term. |
| 8 | **D. Linked list** | int, char, boolean are primitives. |
| 9 | **B. O(m × n)** | Each of the m·n cells is visited once. |
| 10 | **C.** Organize, store and access data efficiently | That is the core purpose of a data structure. |
